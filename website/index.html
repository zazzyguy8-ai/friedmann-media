What gets blocked

A

Site-level blocking

chatgpt.com, claude.ai, gemini.google.com, copilot.microsoft.com, and dozens more redirect to a plain "Blocked by AI Blocker" page instead of loading.

B

Search engine cleanup

Google's AI Overview and Microsoft Copilot / AI answer boxes are stripped out of search results before you see them.

C

Structured local blocklist

Every domain is filed under one category — chatbots, search, writing, coding, image generation, video generation — so you can disable exactly one category at a time.

D

Settings & a running count

One switch for everything, plus a persistent count of how many AI sites have been intercepted since install.

Install AI Blocker

Not yet on the Chrome Web Store. For now, build and load it directly — takes about a minute.

  1. Clone: git clone https://github.com/zazzyguy8-ai/friedmann-media
  2. Build: npm install && npm run build
  3. Open chrome://extensions, enable Developer mode
  4. Load unpacked → select the generated dist/ folder
Distribution: unlimited (open source) github.com/zazzyguy8-ai/friedmann-media
