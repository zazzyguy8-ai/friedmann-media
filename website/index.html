What it does

This isn't an AI detector. It's a blocking system — fast, lightweight, and reliable.

🚫

Block AI websites

Instantly blocks chatgpt.com, claude.ai, gemini.google.com, copilot.microsoft.com, and dozens more — with a clear "Blocked by AI Blocker" page instead of a broken tab.

🔍

Clean search results

Hides Google's AI Overview and Microsoft Copilot / AI answer boxes so search results stay AI-free.

📋

Structured local blocklist

Organized by category — chatbots, search, writing, coding, image generation, video generation — so you can toggle exactly what you want blocked.

📊

Settings & statistics

One switch to enable or disable everything, plus a running count of AI sites blocked over time.

Install AI Blocker

Not yet on the Chrome Web Store — for now, load the development build directly.

  1. Clone the repository: git clone https://github.com/zazzyguy8-ai/friedmann-media
  2. Run npm install then npm run build.
  3. Open chrome://extensions, enable Developer mode.
  4. Click Load unpacked and select the generated dist/ folder.
